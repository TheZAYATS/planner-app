# Planner App

Десктопный планер для управления временем и повышения продуктивности.

## О проекте

Студенты IT-специальностей, фрилансеры и специалисты, работающие за компьютером, сталкиваются с высокой нагрузкой и множеством дедлайнов. При этом им сложно объективно оценивать, как распределяется время между работой, учёбой и отвлечениями.

Приложение объединяет расписание, задачи и дедлайны, автоматическое отслеживание времени в выбранных приложениях и систему уведомлений. Позволяет сопоставлять запланированную нагрузку с фактической.

## MVP

- Импорт расписания
- Управление задачами и дедлайнами
- Отслеживание времени в выбранных приложениях
- Статистика активности
- Персонализированные уведомления

## Стек

- Язык: C# (.NET 8)
- UI: WinUI 3 (XAML)
- Трекинг окон: WindowWatcher (Win32 API)
- Детектор активности: GetLastInputInfo
- БД: SQLite
- Доступ к БД: Microsoft.Data.Sqlite
- Среда разработки: Visual Studio 2022
- Платформа: Windows 10/11
